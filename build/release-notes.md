# v1.64.0 更新说明

## 新功能

- **新增 Cline 双渠道（Cline Free 免费额度池 / Cline Pass 订阅池）**：Cline 是标准 OpenAI 兼容上游，**无需安装客户端、无需签名**，浏览器里点一次确认即可登录（WorkOS 设备授权：显示用户码 + 自动打开授权页，本机轮询入池）。两个池是**相互独立的渠道**，各自独立的账号、模型清单、启停与映射：
  - 免费池有每日免费额度，渠道标「免费」成本档——开了「免费优先」路由时会被正确优先使用；
  - 余额单位 Credits（微 credit ÷ 1e6 换算，欠费时如实显示负值），右上「拉取模型」从官方目录同步两个池各自的模型清单；
  - 模型 id 带池前缀（如 `cline-free/deepseek-v4.1-flash`）——那是上游的**计费通道选择器**，网关原样转发；客户端用不带前缀的短名请求时自动补上本渠道前缀（映射显式可见：管理页里能看到完整 id）；
  - 归池以**官方响应分组**为准而不是按名字前缀猜（免费池里混着别家前缀的免费模型，按前缀猜会让它们在界面上消失）；云池模型实测无权限，不收录；
  - 请求模型无权限时上游返回 403（未订阅该模型 / 仅官方产品面可用），网关**如实透传给客户端、不换号、不冷却账号**——换一个模型或换一个渠道即可，账号本身没问题；限流 429 会解析上游给出的人话等待时长（如「17h 59m」）对齐冷却；
  - 支持三种账号来源：设备授权登录 / 从本机 Cline 客户端登录态导入 / 粘贴凭据（`workos:` 前缀自动补齐）。

## 说明

- Cline 是纯服务端标准协议渠道：刷新令牌自动轮换、auth token 到期前 10 分钟自动续期；同一份 Cline 登录态可以分别在 Free / Pass 两个渠道各导入一次（两个池的账号互不相通）。
- 本版新增 Cline 专项自测（`tools/proxy-cline-selftest.cjs`：协议断言 + 本地假上游端到端，离线可跑）；适配器契约自测与反代全链路 smoke 全绿（14 渠道 × 必需/推荐方法 + 双表一致）。

# v1.63.0 更新说明

## 新功能

- **WebDAV 同步设置页改造**：「测试连接 / 保存设置 / 清除配置」三个按钮改为横向排列（此前被窄栏挤成竖排）；原「号池同步」卡升级为「快捷同步」——用量 / 技能 / 号池 / 记忆四大板块逐一手动触发，各带一句话说明、实时状态与上次同步时间，未配置统一服务器时统一给出「去配置」入口

## 修复

- **AutoClaw 登录三处加固**：国际版「粘贴回调地址」不再假成功（此前提示成功但实际未登录、会话悬挂到 3 分钟超时）；回环回调在初始化完成前的窗口期收到请求（手动刷新旧回调页、上轮残留页预取）不再有崩主进程的隐患；窗口期内取消 / 重复发起登录不再泄漏回环 server
- **号池定时同步不再静默跳过**：同步任务启动瞬间抛错（手动同步进行中 / 同步锁被占）时也回滚计时记账，当天 daily 档失败后下一轮自动补跑（此前当天档期直接丢失）
- **设置页停用板块不再静默改写用户设置**：停用「反代网关」不再把「记住网关开关」强写为关（此前重新启用模块后网关不再自启、且无从得知设置被改），模块开关只做运行时启停；停用「用量统计」时同步取消在途同步，不再把刚关掉的数据库惰性重开
- **配置加载改为深合并**：以默认值为基线补全任意层级的缺失字段，旧版后端 / 字段重命名 / mock 未同步时不再整页白屏（预防性加固，当前版本不可触发）
- **S3 兼容存储文件名修复**：对象列表的 href 按百分号编码，与 WebDAV 侧契约对齐——含空格 / 中文 / & 的文件名此前会得到非法 URL
- 同步锁加固：号池同步的占锁与收尾收进同一保护块，消除极端情况下同步锁永久泄漏、四个模块同步入口被拒需重启恢复的隐患

## 说明

- 「墓碑」内部重构（纯优化，行为与结果不变）：Key 同步的墓碑生效循环改 Key 快照，消除随 Key 数量放大的重复聚合查询（O(n²)）；墓碑写入统一收口；远端无墓碑时不再上传空对象
- 测试脚本沙箱化：failover T10 断言恢复确定性（该偶发红在基线即存在）；checkin-auto 自测默认使用临时沙箱，不再读写真实数据目录
